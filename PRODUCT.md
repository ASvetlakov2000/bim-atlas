# BIM Atlas

Статическая публичная библиотека исследований на русском языке для архитекторов и пользователей Revit/BIM. Владелец: ASvetlakov2000. Публикация: GitHub Pages, bim-atlas, main, корень.

Согласованный интерфейс из пользовательского ZIP — визуальный источник истины: светло-серая бумага, графит, архитектурная типографика, 12 глав, боковое оглавление на компьютере и выдвижное на телефоне. Сохранять дизайн. Основной сценарий: читать исследование на Safari iPhone и Windows, переходить между главами, открывать источники.

Изменения этой задачи: доступность и адаптивность, расширение тем графики Revit и мини-продуктов. Без сборщика, React, базы данных, платного хостинга и изменений SAB.
