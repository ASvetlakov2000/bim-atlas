# BIM Atlas

Публичная библиотека исследований: Revit, BIM, архитектурная графика, AI, обучение и цифровые продукты. Статический сайт без сборщика и платного хостинга.

Сайт: https://asvetlakov2000.github.io/bim-atlas/
Репозиторий: https://github.com/ASvetlakov2000/bim-atlas

## Публикация

GitHub Pages: Deploy from a branch → main → / (root).
Стартовая страница index.html находится в корне. Файл .nojekyll отключает обработку Jekyll.
Каждый commit в main автоматически обновляет сайт. Повторная настройка Pages не нужна.

## Обновление материалов

Все 12 глав находятся в index.html:
- chapters — названия, краткие описания и идентификаторы.
- researchBodies — HTML материалов; ключи совпадают с идентификаторами chapters.
- CSS находится в style, маршрутизация и поиск — в script.

Для небольшой правки откройте index.html на GitHub → Edit → Commit changes в main.
Для больших материалов удобнее локальный редактор: правка → проверка → commit → push.
Сначала сохраняйте резервную копию. В строках researchBodies используется JSON: кавычки, переносы и обратные слеши должны быть корректно экранированы. Можно редактировать объект отдельным скриптом и сериализовать JSON.stringify.

Не меняйте существующие id глав без перенаправлений: прямые ссылки используют #/revit-graphics и аналогичные адреса.

## Дальнейшая структура

Новые самостоятельные страницы можно добавлять по мере появления:
- research/ — исследования и статьи;
- courses/ — страницы курсов;
- products/ — страницы цифровых продуктов;
- assets/images/, assets/video/ — медиа;
- assets/checklists/ — скачиваемые рабочие материалы.

Не создавайте пустые страницы ради структуры. Используйте относительные ссылки ./courses/example.html и ./assets/images/example.png. Ссылки /assets/ ведут от корня домена и не подходят для проекта /bim-atlas/.

Локальный просмотр: python -m http.server 8765, затем http://127.0.0.1:8765/.

## Содержание и ограничения

Сохранены исходные материалы исследования от 09.10.2026 и согласованный монохромный дизайн. Расширены главы об айдентике, графике Revit и мини-продуктах. Добавлен CSV-чек-лист графики, мобильное содержание глав и доступная навигация. Из библиографии удалены три посторонних ссылки на уроки немецкого языка.

Материалы содержат авторские предложения и гипотезы. Указанные цены и трудозатраты не являются прогнозом продаж и не обновляются автоматически. Готовых RTE/RVT/RFA в этой поставке нет: примеры мини-продуктов — план их разработки. Технические ссылки Autodesk приведены в главе 11.

PRODUCT.md и DESIGN.md фиксируют назначение и согласованный интерфейс для будущих изменений. Репозиторий SAB в работе сайта не участвует.
